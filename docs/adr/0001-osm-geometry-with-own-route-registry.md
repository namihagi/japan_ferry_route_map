# 航路形状はOSMから取り、どの航路が存在するかは自前の航路台帳で決める

国土交通省の国土数値情報「定期旅客航路（N09）」は公式データで属性も豊富だが、使わない。理由は3つある。最新が2012年であること、線がすべて港同士の直線であること、そして非商用ライセンスで再配布が禁じられており、公開リポジトリに置けないこと。代わりに OpenStreetMap の `route=ferry` の線を航路形状として使う。こちらは海上ルートに沿った形をしており、ODbL の下で再配布できる。ただし OSM の線は「航路」と一対一には対応せず、船種や運航状態もほとんど入っていない。そこで、航路名・運航会社・船種・運航状態・寄港地・公式サイトは自前の航路台帳に持ち、運航会社の公式サイトを出典とする。OSM は形状の供給元としてだけ使う。実測形状がない航路は、線を描かないのではなく、海上だけを通る最短経路を推定形状として計算して描く。

## Consequences

- 航路台帳にない OSM の線は地図に表示しない。
- OSM 由来のデータを含む配布データは ODbL となり、「© OpenStreetMap contributors」の表示が必要になる。
- N09 は手元で網羅性を確認するための参照に留める。N09 もそこから派生したデータも、リポジトリには入れない。
