# OSM の形状は手動で取り込み、スナップショットとしてコミットする

OSM の `route=ferry` の線は自動では同期しない。スクリプトを手動で実行して取り込み、結果をスナップショットとしてリポジトリにコミットする。定期的に自動取得して自動デプロイする方式は採らない。OSM は誰でも編集できるので、線が分割・削除されたり、誤って編集されたりすることがある。自動同期にすると、それが知らないうちに公開中の地図に反映されてしまう。手動で取り込めば、差分をレビューしてから反映できる。航路台帳の各区間は OSM の way ID を参照し、取り込み時にその ID が見つからなければ警告を出す。推定形状も同じくスナップショットとしてコミットし、再計算するのは区間を追加したときか港の座標を変えたときだけとする。
